\section{Purpose}
\RDSectionIntro{This workbook supports infrastructure and tooling apportionment by preserving a repeatable method for attributing shared technical costs to R\&D activities.}

\RDAuditNote{Do not rely on unsupported flat percentages where a better allocation basis exists. Use tagged resources, environment-specific billing, workload counts, engineer usage logs, or other defensible methods wherever practical.}

\section{Allocation method statement}
Describe the principles used for apportionment. Examples include environment-based allocation, tagged cloud resources, usage-hour ratios, experiment-run counts, or repository / CI workload mapping.

\section{Review checklist}
\begin{RDChecklist}
\item Allocation methods are consistent month to month unless a documented reason exists.
\item Shared production costs are not treated as fully experimental unless justified.
\item Billing references can be reproduced.
\item R\&D percentages tie back to a documented method.
\item Totals flow into the annual claim pack without manual re-keying where possible.
\end{RDChecklist}
