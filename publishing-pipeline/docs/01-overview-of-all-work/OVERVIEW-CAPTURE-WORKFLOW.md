# Overview capture lifecycle

1. **Open the year:** create `claim.yaml` and `program.yaml` from verified entity,
   period, product, ownership, scope, baseline, and objective records.
2. **Screen work:** distinguish a possible technical knowledge gap from ordinary
   engineering. Escalate legal or ownership decisions.
3. **Create uncertainties:** assign a stable `UT-NN` only after recording the
   question, indeterminability basis, knowledge sought, and background evidence.
4. **Create projects:** assign `RND-YYYY-NN`, name its technical problem, link
   uncertainties, people, repositories, and program evidence.
5. **Capture activities contemporaneously:** create neutral `ACT-YYYY-NNN`
   records for candidate experimental, candidate supporting, ordinary, excluded,
   or human-review work. Preserve outside-boundary work explicitly.
6. **Run experiments:** follow the document-02 lifecycle. Document 01 never owns
   experiment methods, results, evaluations, or conclusions.
7. **Update progression:** after a run changes state, update only the project and
   annual synthesis supported by that state. Never paraphrase a run into a more
   favourable outcome.
8. **Register evidence:** assign globally unique `EV-NNNN` values before records
   reference them. Verify a location separately before claiming it was inspected.
9. **Review people and resources:** resolve all participants and reconcile the
   applicability statements with the detailed labour and infrastructure sources.
10. **Close the year:** record year outcomes, unresolved matters, limitations,
    boundary decisions, ownership, and review information. Continuing work keeps
    its existing IDs and receives the next year's dated account without rewriting
    the prior year.
11. **Publish:** validation and all seven warning-free compiles must finish before
    generated TeX and PDFs replace their predecessors.

At every stage, missing legal, ownership, evidentiary, or technical decisions go
to the accountable human. Required unsupported content stops publication.
